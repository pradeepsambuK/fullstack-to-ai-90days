# Finance Copilot Demo

Public demo of the Finance Copilot app: a RAG-powered copilot that answers questions about bills and spending, with built-in documentation on the RAG pipeline and cloud architecture.

Live site: https://pradeepsambuK.github.io/fullstack-to-ai-90days/finance-copilot-demo/

This is a static demo. Nothing is saved: all data is in-memory demo data and resets on refresh. The private, server-backed version lives in the user's Muse space.
